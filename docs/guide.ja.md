## はじめに

1. [Releases](https://github.com/koshizuow/yorishiro/releases) から AppImage をダウンロードし、
   `chmod +x Yorishiro-<version>-x86_64.AppImage` してから実行します。
2. UI の言語は、設定画面の右上で「日本語」を選べます。
3. ステージのカードが、モデルの選択、フェイストラッキングの確認、モデルの配置を案内します。
   Live2D モデルは `.model3.json` ファイルのあるフォルダーです。`~/.local/share/yorishiro/Live2DModels/` にあるモデルは
   自動で表示されます。
4. 少しの間、力を抜いた顔でカメラをまっすぐ見てください。感度ページの**自動キャリブレーション**も使えます。
   1 ステップずつ進むので、各ステップを読んでから動けます。
5. モデルはドラッグで移動、スクロールかピンチで拡大縮小、Shift を押しながらスクロールで回転します。隅の歯車から
   すべての設定を開けます。
6. Yorishiro をアプリケーションメニューに入れてドックにアイコンを出すには、「このアプリについて」ページの
   **アプリケーションメニューに追加**を押します。ファイルを移動したら、もう一度押してください。ファイル自体の
   アイコンはファイルマネージャーで汎用のままのことがあります。これはデスクトップ環境によります。

## ホットキー

モデルにホットキーが付いていれば、読み込んだ時点で使えます。確認や変更は、設定の**ホットキー**ページで行います。
モデルを読み込んでおく必要があります。

- **キーの変更：** ホットキーのキーをクリックし、新しいキーを同時に押します（3 つまで。例：Ctrl+M、Tab+F1）。
  キーを離すと決まります。Esc でキャンセル、Backspace でクリアです。
- **追加：** **ホットキーを追加**を押し、何をするかを選びます。表情、アニメーション、アプリの操作から選べます。
- **長押し：** 長押しをオンにすると、キーを押している間だけ有効になります。

キーボードのホットキーは、アプリのウィンドウがフォーカスされている間に使えます。他のウィンドウ（OBS やゲームを
前面にしているときなど）からも使うには、ユーザーを `input` グループに追加して、ログインし直してください：

```sh
sudo usermod -aG input $USER
```

このグループに入ると、実行するすべてのプログラムがキーボードを読めるようになります。必要なときだけ追加してください。
`id -nG` で確認できます。

## OBS

ステージを、アプリのボタンやメニューを除いて、背景を透過した状態で OBS に送ります。

必要なもの：

- PipeWire 1.4 以降。Ubuntu 25.10、26.04 と Debian 13 は対応しています。Ubuntu 24.04 と Linux Mint 22 は 1.0 なので、
  PipeWire を更新しない限り、アプリは動きますがこの出力は使えません。
- Vulkan レンダラー（初期設定）。
- OBS 32 以降と、別プロジェクトの [obs-pwvideo](https://github.com/hoshinolina/obs-pwvideo) プラグイン。
  OBS は自分より新しい OBS 向けにビルドされたプラグインを読み込まず、このプラグインのリリースは OBS 32 向けです。
  Ubuntu 26.04 の OBS は 32 です。Debian 13 と Ubuntu 25.10 の OBS は 30 なので、Flatpak 版の OBS を使ってください。

プラグインを[リリース](https://github.com/hoshinolina/obs-pwvideo/releases)からダウンロードし、使っている OBS に入れます：

- **ディストリビューションの OBS**（apt、dnf、pacman）：`obs-pwvideo-<version>-x86_64-ubuntu-gnu.tar.xz` を OBS の
  設定フォルダーに展開します：

  ```bash
  mkdir -p ~/.config/obs-studio/plugins
  tar xJf obs-pwvideo-<version>-x86_64-ubuntu-gnu.tar.xz -C ~/.config/obs-studio/plugins
  ```

  Ubuntu と Debian では `.deb` も使え、全ユーザーに入ります：
  `sudo apt install ./obs-pwvideo-<version>-x86_64-linux-gnu.deb`
- **Flathub の OBS**（`com.obsproject.Studio`）：Flatpak は設定を別の場所に置くので、同じファイルをそちらに展開します：

  ```bash
  mkdir -p ~/.var/app/com.obsproject.Studio/config/obs-studio/plugins
  tar xJf obs-pwvideo-<version>-x86_64-ubuntu-gnu.tar.xz -C ~/.var/app/com.obsproject.Studio/config/obs-studio/plugins
  ```

OBS を再起動します。ログ（ヘルプ → ログファイル）に `[obs-pwvideo] plugin loaded successfully` と出れば入っています。

それから：

1. Yorishiro で**ステージを OBS に送る（PipeWire、透過）**をオンにします。
2. OBS で **PipeWire video** ソースを追加し、Yorishiro を選びます。

アプリのウィンドウが隠れたり最小化されたりしていてもフレームを送り続けるので、OBS を上に重ねて置けます。

## 仮想カメラ

Google Meet のように、カメラしか受け付けないアプリ向けです。カメラには透過がないので、アプリの背景（選んだ画像や色、
透明モードでは黒）が映ります。背景を変えるとカメラの映像も変わります。

Ubuntu の場合：

```sh
sudo apt install v4l2loopback-dkms
sudo modprobe v4l2loopback devices=1 video_nr=20 card_label="Yorishiro" exclusive_caps=1
```

`modprobe` の行は再起動するまで有効です。デバイスが見つからないとアプリにこのコマンドが表示され、**再確認**で
再起動せずにデバイスを探し直せます。デバイスが見つかったら、カメラパネルで選んで仮想カメラをオンにし、相手のアプリで
カメラに **Yorishiro** を選びます。

映像のサイズはカメラを開始したときのままで、ウィンドウのサイズを変えるとそれに合わせて拡大縮小されるので、
相手のアプリはそのまま動きます。

## 左右の向き

Yorishiro は鏡のように動きます。あなたが右を向くと、モデルは画面の右側を向きます。

OBS、配信、通話の相手が見るのは、アプリのウィンドウと同じ映像です。Google Meet などのビデオ通話アプリは、ふつう
**自分のプレビュー**だけを左右反転するので、自分のプレビューはアプリと逆向きに見えても、他の人には正しい向きで
見えています。

## iPhone でトラッキング

VTube Studio を入れた iPhone で、Web カメラの代わりに顔をトラッキングできます。接続方法は 2 つあります。どちらも
iPhone で確認済みで、Web カメラと同じく鏡のようにモデルが向きます。VTube Studio の項目名は英語の表示で書いています。

**PC 接続（VTube Studio 向けに作られたモデルにおすすめ）。** モデルの入力（頭の角度、目、口）をスマホ側が
自分のキャリブレーションで計算します。パソコン版の VTube Studio が受け取るのと同じ値なので、その値を前提にした
モデル（例：目を全開にすると 0.5）もそちらと同じように見えます。

1. Yorishiro でカメラパネルを開き、トラッキングの入力に **VTube Studio（Wi-Fi）**を選んで**サーバーを起動**を押します。
   パネルにこのパソコンのアドレスが表示されます。
2. iPhone を同じ Wi-Fi につなぎます。VTube Studio の設定（歯車）を開き、PC 接続（Wi-Fi）の項目にそのアドレスと
   ポート 25565 を入力して、**Connect to PC** をオンにします。
3. スマホがつながると、パネルの表示がオンに変わります。接続待ちのままなら、パソコンのファイアウォールが TCP ポート
   25565 をふさいでいるかもしれません。ufw の場合：`sudo ufw allow 25565/tcp`

**VSeeFace モード。** スマホは顔の形の生の値（ARKit の 52 個の値）を送り、入力は Yorishiro が計算します。
アプリのこの機能は無料です。

1. iPhone を同じ Wi-Fi につなぎます。下で表示される IP が他の機器（例：`192.168.x.x`）と違って見えるなら、
   モバイルデータ通信をオフにします。
2. VTube Studio でカメラのボタンを一度タップして、トラッキングを始めます。
3. 設定を開いて **VSeeFace** の項目までスクロールし、**Activate** をオンにします。
4. **Show IP list** を押して IPv4 アドレスを控えます。ポートは常に 21412 です。
5. Yorishiro でトラッキングの入力に **iOS ブレンドシェイプ（VTS）**を選び、**ホスト名（スマホ）**にスマホのアドレスを
   入力して**スマホに接続**を押します。スマホの **Connected VSF Clients** にこのパソコンが表示されます。
6. 何も届かないなら、データが届く UDP ポート 50650 をファイアウォールがふさいでいるかもしれません：
   `sudo ufw allow 50650/udp`

どちらの場合も：

- スマホの VTube Studio は開いたまま、画面もついたままにしてください。アプリがバックグラウンドになるとモデルが止まります。
- PC 接続の項目の **Streaming Mode** は、パソコンがつながるとスマホの画面を暗くします。スマホの画面を見たいならオフにします。
- 一度に使うのはどちらか 1 つにしてください。

## 1 台のパソコンで複数人

アプリをもう一度開きます。各コピーは次の番号を使います。`--instance=2` で指定もできます。

- 各コピーはそれぞれの設定を持ち、空いているカメラを使います。モデルライブラリは共有です。
- OBS のストリームは `Yorishiro`、`Yorishiro-2` のように名前が付きます。プラグインのポートは 8001、8002 と続きます。
- 2 つのコピーが同時に 1 台のカメラを読むことはできません。2 つ目はカメラが使用中と表示して、そのまま動き続けます。

コピーごとにトラッキングを行うので、何人まで使えるかはパソコンの性能によります。

## 困ったときは

| 起きていること | 対処 |
|---|---|
| Wayland でウィンドウが出るまで 1 分ほどかかる | デスクトップポータルが応答していません。お使いのデスクトップのバックエンド（例：`xdg-desktop-portal-wlr`、`xdg-desktop-portal-hyprland`）を入れて起動してください。 |
| キーボードのホットキーが効かない | アプリのウィンドウをクリックしてフォーカスしてください。他のウィンドウからは[ホットキー](#ホットキー)を参照。 |
| OBS に Yorishiro のソースがない | **ステージを OBS に送る**がオンか確認し、次にプラグインと OBS のバージョンを確認してください。 |
| 仮想カメラの一覧にデバイスがない | [仮想カメラ](#仮想カメラ)の `modprobe` の行を実行してから、**再確認**を押してください。再起動のたびに必要です。 |
| iPhone のトラッキングが接続待ちのまま | アドレスと、スマホが同じ Wi-Fi にいるかを確認し、次にファイアウォールを確認してください。[iPhone でトラッキング](#iphone-でトラッキング)を参照。 |
| カメラが使用中 | 別のアプリか別のコピーがカメラを使っています。それを閉じるか、別のカメラを選んでください。 |
